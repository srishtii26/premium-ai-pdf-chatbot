# 🚀 Premium AI PDF Chatbot

A modern AI-powered Multi-PDF RAG (Retrieval Augmented Generation) Chatbot built using Streamlit, LangChain, Ollama, FAISS, and Sentence Transformers to intelligently interact with PDF documents using local AI models.

The platform combines semantic search, document retrieval, AI-powered responses, analytics dashboards, intelligent summaries, and premium UI/UX into one unified AI workspace.

# 🚀 Overview

The Premium AI PDF Chatbot is an advanced AI-powered document assistant designed to simulate modern intelligent document interaction systems used in enterprises, research environments, analytics platforms, and AI productivity tools.

The platform allows users to:

* Upload multiple PDF documents
* Interact with documents using AI
* Perform semantic document search
* Generate AI-powered summaries
* Analyze uploaded document metrics
* View intelligent insights
* Interact through a premium AI interface

---

# 💡 Problem Statement

Traditional document reading systems are inefficient because users often struggle with:

* Searching large PDFs manually
* Understanding long documents
* Extracting important information quickly
* Managing multiple documents together
* Lack of intelligent interaction
* Time-consuming document analysis

Conventional PDF viewers do not provide AI-powered understanding or semantic retrieval capabilities.

---

# 🎯 Solution

This platform solves these problems using:

* Retrieval Augmented Generation (RAG)
* Semantic vector search
* Local Large Language Models
* Intelligent document chunking
* AI-powered summaries
* Interactive analytics dashboards
* Multi-document retrieval

The project demonstrates how modern AI-powered knowledge assistants work in real-world environments.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/srishtii26/premium-ai-pdf-chatbot.git
```

---

## 2️⃣ Navigate Into Project

```bash
cd premium-ai-pdf-chatbot
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Ollama

```bash
ollama run tinyllama
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```
